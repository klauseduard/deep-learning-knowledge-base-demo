1. Softmax: Logits to Probabilities

A 3-class classifier (Cat, Dog, Fish) outputs logits — raw, unbounded scores from the last linear layer. The true class is Cat.

Logits: $z_{\text{cat}} = 2.0$,   $z_{\text{dog}} = 1.0$,   $z_{\text{fish}} = -1.0$
True class: Cat   →   one-hot target $y = [1, 0, 0]$

These logits can be any real numbers — positive, negative, or zero. They are not probabilities. Softmax converts them to a probability distribution: non-negative values that sum to 1.

Step 1 / 6
Softmax amplifies differences. The logit gap between Cat (2.0) and Fish (-1.0) is only 3.0, but the probability ratio is 7.389 / 0.368 = 20:1. The exponential makes confident predictions very confident.

2. Cross-Entropy: Probability to Loss

Now that we have probabilities, we can compute the loss. Cross-entropy asks one simple question: what probability did the model assign to the correct answer?

Step 1 / 5
The entire cross-entropy computation reduces to: take the predicted probability of the correct class, apply $-\log$. That's it. All the other predicted probabilities don't directly appear in the loss — they affect it only indirectly through the softmax normalization (they determine what probability is "left over" for the correct class).

3. The Gradient: Loss to Update Direction

To train the network, we need the gradient of the loss with respect to each logit: $\frac{\partial \mathcal{L}}{\partial z_c}$. This tells us which direction each logit should move to reduce the loss.

Step 1 / 4
The gradient for cross-entropy + softmax is $\hat{y}_c - y_c$ — the simplest possible form. This is not a coincidence: the combination of softmax and cross-entropy was designed so that the complicated exponentials in softmax and the logarithm in cross-entropy cancel during differentiation, leaving this clean result.

4. Applying the Update

The logit gradients flow backward through the network to update all parameters. But for illustration, let's see what happens if we directly update the logits themselves with learning rate $\eta = 0.5$:

Step 1 / 3
In a real network, you don't update logits directly — they're computed from the layer below. The gradients propagate backward through all layers via backpropagation, updating the weights that produce these logits. But the direction of change is the same: the true class logit goes up, the wrong class logits go down. For a full forward-backward-update example through the network, see the SGD math walkthrough.

5. Autoregressive Cross-Entropy — Loss for Sequences

Language models don't classify a single input — they predict the next token at every position in a sequence. The loss is the sum of per-position cross-entropies.

Sequence: "The cat sat"
Tokens: ["The", "cat", "sat"]   (vocabulary of 5 words for this toy example)
Step 1 / 5
Autoregressive cross-entropy is just standard cross-entropy applied independently at each position, then summed. Each position is a separate classification problem: "given the tokens so far, which token comes next?" out of the entire vocabulary. A language model with a vocabulary of 50,000 tokens is doing 50,000-class classification at every position.

6. Contrastive Loss — Learning to Match Pairs

Contrastive loss (used in CLIP, SimCLR, etc.) doesn't classify into fixed categories. Instead, it learns which things go together. Given a batch of paired examples (e.g., images and their captions), the model should match each item to its correct partner.

Batch of 3 image-text pairs:
Pair 1: [photo of cat] ↔ "a fluffy cat"
Pair 2: [photo of dog] ↔ "a brown dog"
Pair 3: [photo of fish] ↔ "a goldfish in a bowl"
Step 1 / 5
Contrastive loss reuses the same cross-entropy math — the similarity matrix rows and columns are treated as classification problems, with softmax converting similarities to "match probabilities." The difference is that the "classes" aren't fixed categories (cat/dog/fish) but the other items in the batch.
